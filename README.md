# Tic-Tac-Toe C++ (graphics.h)

This project was developed for the **Computer Graphics and Image Processing Sessional (CIT 422)** course at Patuakhali Science and Technology University (PSTU). It is a classic multiplayer Tic-Tac-Toe game implemented in C++ using the graphics.h library.

## Features
- **Graphical User Interface (GUI):** A fully functional game board built with C++ graphics.
- **Multiplayer Mode:** Supports two players taking turns on the same machine.
- **Score Tracking:** Tracks which player won or if it's a draw.
- **Win Detection:** Automatically highlights the winning row/column/diagonal.

## Requirements
To run this project, you need an IDE configured with the BGI (Borland Graphics Interface) / graphics.h library, such as **Code::Blocks**.
